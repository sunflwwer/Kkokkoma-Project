# Into the Memories

판도라큐브 꼬꼬마 프로젝트에서 제작한 **중세 판타지 배경의 2D 파쿠르 게임**입니다.

## 🎯 프로젝트 소개

플레이어는 기억을 잃은 용사가 되어 다양한 스테이지를 통과하고, 과거의 기억을 되찾아가는 여정을 경험합니다.

## 👩🏻‍💻 담당 역할

프로그래밍 담당으로 참여하여 Unity 기반의 게임 시스템과 스테이지 기능을 구현했습니다.
